# زرنگار — حسابداری طلافروشی

نسخه اولیه وب‌اپ فارسی و راست‌چین با قابلیت نصب به‌صورت PWA روی اندروید.

## امکانات فعلی
- ثبت و جست‌وجوی مشتریان
- دفتر گردش حساب هر مشتری
- ثبت فروش و خرید طلا، دریافت و پرداخت وجه، تحویل و دریافت طلا
- محاسبه جداگانه مانده نقدی و مانده وزنی
- ورود صوتی فارسی در مرورگرهای پشتیبانی‌شده
- خروجی پشتیبان JSON
- ذخیره محلی اطلاعات در همان دستگاه

## اجرا
فایل‌ها را روی یک میزبان HTTPS مانند GitHub Pages منتشر کنید و نشانی سایت را در Chrome اندروید باز کنید. از منوی Chrome گزینه Install app یا Add to Home screen را بزنید.

## نکته مهم
این نسخه اولیه است و اطلاعات در حافظه همان مرورگر ذخیره می‌شود؛ همگام‌سازی ابری، ورود چندکاربره، چاپ فاکتور، محاسبات کامل اجرت/مالیات/سود و آزمون‌های حسابداری باید در نسخه‌های بعدی اضافه و بررسی شوند. حتماً از پشتیبان JSON استفاده کنید.
