# زرنگار — حسابداری طلافروشی

نسخه ۲ یک وب‌اپ فارسی و راست‌چین با قابلیت نصب به‌صورت PWA روی اندروید است.

## امکانات
- ثبت و ویرایش مشتری و شماره تماس
- دفتر گردش جداگانه هر مشتری
- ثبت فروش و خرید طلا، دریافت و پرداخت وجه، دریافت و تحویل طلا
- محاسبه مستقل مانده نقدی و مانده وزنی با توضیح جهت بدهکاری/بستانکاری
- ویرایش و حذف رویدادها و محاسبه مجدد مانده‌ها
- گزارش رویدادها بر اساس بازه تاریخ و مشتری، همراه چاپ
- ورود صوتی فارسی در مرورگرهای پشتیبانی‌شده و انتقال متن به فرم برای بازبینی
- خروجی و بازیابی پشتیبان JSON
- ذخیره محلی اطلاعات در همان مرورگر و دستگاه

## نصب روی اندروید
پس از انتشار روی GitHub Pages، نشانی سایت را در Chrome باز کنید و از منوی مرورگر گزینه Install app یا Add to Home screen را انتخاب کنید. نصب PWA به HTTPS نیاز دارد.

## نکات مهم حسابداری و امنیت اطلاعات
- مانده نقدی منفی یعنی مشتری به فروشگاه بدهکار است؛ واریز وجه مشتری فقط مانده پولی را افزایش می‌دهد.
- مانده طلای مثبت یعنی فروشگاه به مشتری طلا بدهکار است؛ ثبت دریافت یا تحویل طلا فقط مانده طلایی را تغییر می‌دهد.
- دریافت وجه و دریافت طلا مستقل از هم ثبت می‌شوند و حساب دیگر را تغییر نمی‌دهند.
- داده‌ها در این نسخه فقط در حافظه مرورگر همان دستگاه نگهداری می‌شوند؛ همگام‌سازی ابری و چندکاربره وجود ندارد.
- این نسخه هنوز جایگزین نرم‌افزار حسابداری تأییدشده و بررسی‌شده برای امور مالیاتی/قانونی نیست. قبل از استفاده عملیاتی، محاسبات با چند سناریوی واقعی و توسط حسابدار طلافروشی کنترل شوند.
- اجرت، سود و متعلقات فعلاً به‌صورت مبلغ دستی ثبت می‌شوند؛ محاسبه خودکار اجرت، مالیات، عیار، قیمت روز و سود هنوز پیاده‌سازی نشده است.
- مرتب خروجی پشتیبان بگیرید و فایل پشتیبان را در محل امن نگهداری کنید.
